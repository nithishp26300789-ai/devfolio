# Developer Portfolio

A responsive single-page developer portfolio built with semantic HTML5, modern CSS Grid/Flexbox layouts, and custom CSS color variables.

## Live Demo
- **Live Site:** https://your-username.github.io/devfolio/
- **Repository:** https://github.com/your-username/devfolio

## Features
- **Semantic Structure:** Organized using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags.
- **Color & Type System:** Controlled dynamically with CSS custom properties (`--brand`, `--ink`, `--bg-main`).
- **Flexbox & Grid Layout:** Header uses Flexbox for aligned navigation; Projects section uses a multi-column CSS Grid.
- **Responsive Design:** Utilizes a `@media (min-width: 768px)` breakpoint and fluid image bounds (`max-width: 100%`) for desktop and mobile displays.
